# Learning Log

## 2026-07-31 — ATS Lite 첫 마일스톤

- 오늘의 목표: 채용 요청부터 전자결재 승인, 채용공고 초안 생성까지 연결한다.
- 구현한 기능: 요청 상태, 공통 결재 연결, 승인·반려 동기화, 공고 1회 생성 제약.
- 배운 Python 개념: Service가 여러 Repository를 조합해 업무 규칙을 표현하는 방법.
- 배운 FastAPI 개념: Router는 입력·응답만 맡기고 Service 의존성을 주입하는 구조.
- 배운 SQLAlchemy 개념: 같은 Session의 변경을 마지막 `commit()` 하나로 묶으면 트랜잭션이 된다.
- 배운 PostgreSQL/SQL 개념: FK와 Unique 제약으로 요청-공고 1:1 관계를 보조한다.
- 배운 테스트 개념: 공고 생성 함수를 실패시켜 승인·요청 상태가 함께 롤백되는지 확인한다.
- 코드 없이 설명할 수 있는 내용: 결재 문서는 승인 상태, 채용 요청은 업무 상태를 별도로 가진다.
- 다음 작업: 지원자 등록이나 AI 기능을 시작하기 전에 승인된 공고의 조회 범위를 다시 점검한다.
